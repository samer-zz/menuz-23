# تقرير لوحات التحكم والإدارة (Stage 8) — MENUZ

**التاريخ:** 2026-11-20  
**الحالة:** `COMPLETED & TESTED` (تجميع الواجهات، Rate Limiting، وعزل التقييمات) | `IMPLEMENTED — NOT LIVE-TESTED` (مع مصادقة حيّة)

---

## 1. لوحة الإدارة العليا (`/admin` — `SuperAdminClient`)
- **الأداء مع التوسع:** تحميل الجهات بترقيم (12 لكل صفحة) وبحث فوري، وجلب قائمة منيو أي جهة عند الطلب فقط عبر `GET /api/admin/tenant-menu?tenantId=...`.
- **تخصيص الألوان:** دعم الألوان الأساسية والمميزة وألوان الخلفية والنص والبطاقات الاختيارية في نموذج الجهة (`/api/admin/tenants`) مع Fallback تلقائي قبل تطبيق `005`.
- **تبويب الطلبات الموثّقة (`orders`):** عرض الطلبات المسجلة خادمياً وإجمالياتها لكل الجهات.
- **تبويب تقييمات التجربة (`feedbacks`):** متاح حصرياً للـ Super Admin ويعرض المتوسط العام وملاحظات العملاء (مع قراءة توافقية من `audit_logs` قبل تطبيق `005`).
- **تقييد المعدّل الإداري:** تم تزويد مسارات `/api/admin/users` و`/api/admin/tenants` بـ `enforceRateLimit` fail-closed لكل حساب مشرف.

## 2. لوحة تحكم المستأجر (`/dashboard` — `ClientDashboardClient` & `TenantMenuManager`)
- **إدارة متكاملة:** الأقسام، الأصناف والأسعار والشارات والصور المضغوطة، العروض المجدولة، الإشعارات الفورية + Web Push، المحافظ الإلكترونية، وبيانات التواصل والتوصيل.
- **تبويب الطلبات (`orders`):** يعرض طلبات الجهة نفسها فقط المحمية بـ RLS.
- **العزل الصارم:** لا يحتوي مسار أو مكوّن لوحة المستأجر على أي وصول لجدول `order_feedback` أو تقييمات العملاء الحساسة.
