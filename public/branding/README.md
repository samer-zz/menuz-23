## الألوان الرسمية (Brand Palette)
- **Primary Navy Blue**: `#0B2D5B` (وداكن `#040E21`)
- **Primary Orange**: `#FF7A00` (وتدرّج `#FF9E2C` → `#E66400`)

يمكن استبدال شعار أي جهة أو رفع صور الغلاف والأصناف مباشرة من لوحة تحكم مدير النظام أو لوحة العميل، ويتم تخزينها في Supabase Storage Bucket `menus-media`.
