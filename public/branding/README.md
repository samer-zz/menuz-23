## الأبعاد الموصى بها لرفع أصول الجهات (Recommended Upload Dimensions)
- **شعار الجهة (`logo`)**: `512 × 512` بكسل (مربع PNG أو WebP بخلفية شفافة أو داكنة).
- **صورة الغلاف (`cover`)**: `1600 × 600` بكسل (بنسبة عرضية عريضة).
- **أيقونة المحفظة الإلكترونية (`wallet`)**: `128 × 128` بكسل.
- **أيقونة التبويب (`favicon`)**: `32 × 32` و`16 × 16` بكسل (بالإضافة إلى `192×192` و`512×512` لتطبيق PWA).

## الألوان الرسمية (Brand Palette)
- **Primary Navy Blue**: `#0B2D5B` (وداكن `#040E21`)
- **Primary Orange**: `#FF7A00` (وتدرّج `#FF9E2C` → `#E66400`)

يتم ضغط الصور تلقائياً في المتصفح إلى صيغة WebP قبل الرفع إلى Supabase Storage Bucket `menus-media`.
