## ما الجديد في v3.0 (What's New in v3.0)

- **PWA ديناميكي لكل منيو (`/api/manifest/[slug]`)**: كل منيو مطعم (`/m/[slug]`) يمتلك Manifest ديناميكياً يجعل التطبيق المثبت على شاشة العميل يفتح مباشرة على منيو ذلك المطعم (`start_url = /m/[slug]`) مع زر تثبيت مخصص وأنيق.
- **إشعارات فورية حية (In-App Realtime Notifications)**: إرسال إشعارات من لوحة التحكم لتظهر لحظياً عبر Supabase Realtime داخل جرس الإشعارات في المنيو، مع حذف تلقائي بعد 7 أيام.
- **المنيو التجريبي التفاعلي (`/m/demo`)**: كيان حقيقي في قاعدة البيانات (`is_demo = true`) لتجربة المنصة فوراً من الصفحة الرئيسية، مع إمكانية إدارته من لوحة `Super Admin` وخيار إنشاء قالب مبدئي عند إضافة أي جهة جديدة.
- **مبدّل طريقة العرض + دخلة ترحيبية فاخرة**: التبديل بين (**بطاقات / قائمة / كلاسيكي**) مع الحفظ في `localStorage`، ودخلة ترحيبية CSS-only مدتها ≤ 1 ثانية مرة واحدة لكل جلسة.
- **مولّد QR مطوّر بالشعار**: تضمين شعار الجهة في منتصف رمز QR مع شعار مينوز، وتصدير فوري بصيغتي **PNG** و**SVG**.
- **جاهزية 150+ جهة**: فهارس DB محسّنة في `002_v3_upgrade.sql` وبحث + ترقيم صفحات في لوحة الإدارة، بالإضافة إلى بادج **"أول منيو مجاناً لمدة شهر"**.

## نظرة عامة (Overview)

**مينوز | MENUZ** هي منصة سحابية متكاملة متعددة الجهات (Multi-Tenant SaaS) لإدارة القوائم الرقمية (Digital QR Menus) للمطاعم والكافيهات وعربات الطعام، مبنية بـ **Next.js (App Router)** و**TypeScript** و**Tailwind CSS** و**Supabase** و**Vercel**.

### المميزات الرئيسية (Key Features)
- **تصميم عربي فائق الفخامة (RTL-First)**: دعم كامل للغة العربية، وضع ليلي افتراضي مع تبديل للوضع النهاري، وحركات سلسة عبر Framer Motion.
- **تجربة منيو تفاعلية (`/m/[slug]`)**:
  - شريط عروض مجدولة متحرك (يختفي تلقائياً بعد انتهاء التاريخ).
  - عرض الأصناف المميزة + أقسام لاصقة للتنقل السريع + بحث وفلترة بالشارات.
  - سلة طلبات منزلقة بعدّاد حي وشاشة فاتورة قابلة للتعديل.
  - دعم الدفع النقدي والمحافظ الإلكترونية (مع نسخ رقم المحفظة وإدخال رقم العملية).
  - إرسال الفاتورة مباشرة عبر **واتساب** أو **SMS**.
- **عزل أمني صارم (Row Level Security)**:
  - `Guest`: تصفح المنيو العام والإشعارات النشطة فقط.
  - `Client Admin`: إدارة أقسام وأصناف وعروض وإشعارات ومحافظ وإحصائيات جهته فقط دون تعديل اسم الجهة أو الشعار أو رؤية بيانات غيره.
  - `Super Admin`: تحكم كامل بالجهات (بما فيها المنيو التجريبي)، الحسابات، الصلاحيات، إيقاف/تشغيل أي منيو برسالة مخصصة، مقارنة الأداء، وسجل التدقيق (Audit Log).
- **PWA + Offline**: تطبيق ويب تقدمي قابل للتثبيت لكل جهة مع تخزين مؤقت ذكي وصفحة مخصصة عند انقطاع الإنترنت.

## التثبيت والتشغيل المحلي (Local Setup)

1. استنساخ المستودع وتثبيت الحزم:
   ```bash
   git clone https://github.com/samer-zz/menuz-23.git
   cd menuz-23
   npm install
   ```

2. نسخ ملف البيئة وتعبئة بيانات Supabase:
   ```bash
   cp .env.example .env.local
   ```

3. تنفيذ التهجير (Migrations) على مشروع Supabase من مجلد `supabase/migrations/`:
   - `001_initial_schema.sql`: الجداول الأساسية، الفهارس، الدوال، سياسات RLS، ومخزن الصور.
   - `002_seed_indomito.sql`: البيانات الأولية لجهة إندوميتو (INDOMITO).
   - `002_v3_upgrade.sql`: ترقية v3.0 (جدول `notifications` + Realtime + `is_demo` + فهارس 150+ جهة + بيانات `/m/demo`).

4. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

## حدود الخطة المجانية (Free Tier Limits & Scaling Notes)
- **Supabase Free**: قاعدة بيانات 500MB، مساحة تخزين 1GB، و50,000 مستخدم نشط شهرياً، و200 اتصال Realtime متزامن. يستوعب النظام **150+ جهة** بسلاسة بفضل الفهارس المخصصة وضغط الصور التلقائي، مع ملاحظة:
  - عدم توفر تفعيل `pg_cron` مباشرة بصلاحيات PostgreSQL العادية على بعض مشاريع الخطة المجانية؛ لذا تم اعتماد **Vercel Cron يومي** (`/api/cron/cleanup-notifications`) بالإضافة إلى تصفية `expires_at > now()` في سياسات RLS لضمان حذف وإخفاء الإشعارات المنتهية بعد 7 أيام مجاناً.
  - التوسع فوق عدة آلاف من الصور المرفوعة أو زيادة حجم أحداث التحليلات اليومية بشكل كبير قد يتطلب مستقبلاً الترقية إلى Supabase Pro.
- **Vercel Hobby**: استضافة مجانية غير محدودة للمواقع التجارية الصغيرة/المشاريع الأولية مع حد تنفيذ Serverless مناسب ومهمتي Cron يوميتين (`/api/health` و`/api/cron/cleanup-notifications`).
- **النسخ الاحتياطي الدوري**: ضمن الخطة المجانية يُنصح بتصدير نسخة احتياطية أسبوعية عبر `pg_dump` أو Supabase SQL Editor كما هو موثق في `docs/OPERATIONS_AR.md`.
